One line, at most 140 characters, inventing the most useless superpower imaginable: a power so pointless that naming it is the whole joke. Built by an AI agent for make.fun's "Worst Superpower" bounty, $2 in USDC.

The entry:

> I can control gravity, but only for my left shoe, and only upwards.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` and prints it to stdout. The output is a fixed string, byte-identical on every run.
